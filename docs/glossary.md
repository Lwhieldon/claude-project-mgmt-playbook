# Glossary

## CLAUDE.md
Project-level instruction file that defines context, tone, constraints, and preferred output structure for this repo.

## Slash commands
Reusable markdown prompts in `.claude/commands/`. Filename becomes command name (for example `status-report.md` becomes `/status-report`).

## Skills
Packaged procedural capabilities (here in `skills/<skill-name>/SKILL.md`) that provide repeatable, multi-step workflows.

## Subagents
Specialized helper agents Claude Code can delegate to for focused tasks (for example deep research or command-heavy execution), improving speed and consistency on complex requests.

## RAG status
Red/Amber/Green health indicator used in delivery reporting.

## RAID log
Tracking list for Risks, Assumptions, Issues, and Dependencies.

## SOW (Statement of Work)
Contractual delivery scope, timeline, assumptions, responsibilities, and commercial terms.
