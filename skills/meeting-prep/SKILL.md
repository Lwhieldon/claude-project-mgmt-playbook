# Meeting Prep Skill

## Use when
- Preparing steering committees, sponsor check-ins, or workstream syncs.

## Procedure
1. Determine audience priorities (timeline, budget, risk, value realization).
2. Build timeboxed agenda aligned to meeting objective.
3. Draft top talking points with evidence from source artifacts.
4. Anticipate likely questions and draft concise responses.
5. Create explicit decisions required, with owner and deadline.

## Output format
- Agenda with timeboxes
- Talking points (max 7)
- Q&A prep table
- Decisions required table
- 3-line opening script for the presenter
